테스트는 두 층이다.

| 층 | 무엇을 보나 | 어떻게 돌리나 |
|---|---|---|
| **자동 (스크립트 회귀)** | `scripts/` 3종이 계약대로 동작하는가 | `python3 tests/run_tests.py` — 픽스처만 쓰고 사이트에 붙지 않는다. 현재 **65건 전건 통과** |

각 엣지 케이스에는 검증 층을 표시한다: `[자동]` 회귀 테스트에 있음 · `[수동]` 실사이트 실행으로 확인 · `[문서]` 어댑터/SKILL의 지시로 방어(위반 시 수동 검출).

## 2. 스토리별 완주(happy path) 기준

스토리별 완주 시나리오는 딱 3개다 — 인사일런스 라인시트 / 데님팬츠(범위 합의) 전수조사 /
무신사 바지 랭킹 top 100 diff. **통과 기준은 [SPEC.md](SPEC.md) §4의 성공 기준을
그대로 쓰고 여기 반복하지 않는다.** 실패 양상(엣지)은 전부 §3 카탈로그에 있다.
