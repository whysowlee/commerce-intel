# platform-ssf

SSF샵에서 **화면에 노출된 값만** 모아 데이터 계약 JSON을 만든다. DB 적재·분석·리포트와
공통 규칙(속도·차단 중단·추정 금지·순회 상한)은 `commerce-intel` 오케스트레이터가 갖는다.

> ⚠️ **이 스킬은 초안(draft)이다.** `「미검증」` 표기 항목은 사실이 아니라 확인 과제다.
> 미검증 항목에 의존하는 수집을 하게 되면 그 사실을 사용자에게 먼저 알린다.

## D30 — 수집 방식 제약 (사용자 결정, 2026-08-03)

**사용자 지시 건별 수집만 한다. 크론 무인 축적을 등록하지 않는다.** robots.txt가
Claude UA 3종(ClaudeBot·Claude-User·Claude-SearchBot)을 명시 허용하지만(2026-08-03 실측),
수집 방식은 D30으로 확정됐다. `snap_ranking_any.py --cron` 류의 주기 등록 요청이 오면
이 제약을 알리고 멈춘다. `/secured/`·`/raffle/`은 robots가 금지한 경로다 — 건드리지 않는다.

## 수집 절차

1. **`references/adapter.md`를 먼저 읽는다** — 검증된 요청 스킴·필드 매핑·함정이
   실측 일자와 함께 있다. 어댑터에 없는 스킴을 사실처럼 쓰지 않는다.
2. **카테고리 코드 확인** — `sitemap_category.xml`에 1,353개 카테고리 URL이 전부
   나열된다. 코드는 접두사+3자 세그먼트 계층(예: `SFMA41` 여성 → `SFMA41A04` 팬츠 →
   `SFMA41A04A07` 데님). 대분류 10종은 adapter.md §3. 검색 경로는 「미검증」이라
   카테고리 경로로 대상을 잡는다. 브랜드 단위 목록 경로도 「미검증」이다.
3. **총계 확보** — 목록 응답의 hidden input `ctgryGodsListTotalRow`가 독립 총계다.
   **총계는 필터의 함수다**(기본 4,233 / 품절제외 4,091 실측) — `source_total`에 담을 때
   읽은 시점의 필터 상태를 `meta.notes`에 병기한다. 수집 건수를 넣지 않는다(순환 검증 금지).
4. **목록 순회** — `selectProductList`를 `currentPage` 증가로 돈다. 페이지당 60개 고정.
   깊은 페이지 상한 없음(p2700 정상 실측). 종료 판정은 수집 건수의 총계 도달 + 빈 페이지.
5. **품절 처리** — **기본 목록이 품절 포함이다**(제외가 opt-in: `benefit=EXC_SLDOUT`).
   단 판매량순 정렬에서는 품절품이 꼬리로 밀린다 — 1페이지만 보고 "품절 미노출"로
   판정하지 마라(adapter.md 함정 1).
6. **검증 대조** — 수집 건수를 총계와 나란히 보고한다. 다르면 그 차이를 밝힌다.

## 이 플랫폼의 노출 지표

| 계약 필드 | 노출 | 주의 (상세는 adapter.md) |
|---|---|---|
| review_count / rating | 노출 | rating은 **5점 만점 그대로**(변환 불요). 리뷰 없는 상품은 결측 → `null` 정확 (실측 결측 28.3%) |
| like_count | 노출(하트) | 결측 0% 실측 |
| view_count | **미노출** | 항상 `null` |
| purchase_count | **미노출** | 항상 `null`. 판매량순 정렬(`SALE_QTY_SEQ`)은 있지만 수치는 안 준다 |
| viewers_now / buyers_now | **미노출** | 항상 `null` |
| category | 요청 dspCtgryNo + 상세 JSON-LD 경로("여성 » 팬츠 » 와이드") | 목록 카드에는 없다 |

미노출 필드는 항상 `null`이다 — 다른 출처에서 끌어와 채우지 않는다.

## SSF샵 고유 특성 (상세는 adapter.md)

- **별도 BEST 랭킹 페이지가 없다** — `SALE_QTY_SEQ`(판매량순)가 랭킹 프록시다.
  갱신 주기는 「미검증」.
- **연령대별 인기순**(`preferAge=1020AGE/30AGE/40AGE/50AGE_OVER`) — 다른 플랫폼에 없는
  축이다. 쓰게 되면 `raw_extras`에 담고 해석하지 않는다.
- 목록 카드에 색상 변형 목록이 노출된다 — `raw_extras` 후보.
- 상품 URL의 브랜드 슬러그는 장식이다(`/x/{godNo}/good`도 200) — URL 조립은 godNo만 있으면 된다.
